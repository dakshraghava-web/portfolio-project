# Personal Portfolio Website (Web Dev I - Lab Assignment 1)

A clean, accessible, one-page personal portfolio website built with pure semantic HTML5 for **Web Dev I — Lab Assignment 1**.

## Purpose

This project demonstrates foundational HTML5 structure and best practices before applying CSS styling in future labs:

- **Semantic HTML5 layout** using `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
- **In-page navigation** with anchor links (`#about`, `#projects`, `#skills`, `#contact`, and `#top`).
- **Accessibility features**, including a skip-to-content link, `aria-label` / `aria-labelledby` attributes, descriptive `alt` text for images, table header scopes (`scope="col"`), and explicit `<label for="...">` associations.
- **Structured content** featuring a hero banner, about section with a profile image, unordered list of sample projects, technical skills table, and a validated contact form with `required` fields and placeholders.

## How to View

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Use the navigation links at the top to jump to **About**, **Projects**, **Skills**, or **Contact**, and test the contact form validation.
